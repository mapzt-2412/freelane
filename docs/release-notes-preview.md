FreeLane v0.1.0-preview.12 for Apple Silicon Macs (macOS 14+).

This P2 preview adds opt-in Unicode text clipboard controls and verified Windows guest-agent lifecycle operations. The original roadmap remains in progress.

- In Display, enable Share text clipboard, then Send clipboard to guest or Copy clipboard from guest. Vietnamese/emoji text transfers are limited to8KiB UTF-8. This is explicit button-based transfer; automatic synchronization, images/rich text and full Coherence video remain pending.
- The updated agent advertises protocol v4 clipboard only when its native backend initializes. v1/v2 operations and v3 discovery remain compatible. Consent resets on opening a VM; revoked queued requests are canceled before transmission. Clipboard data/guest-provided error payloads are excluded from routine notices and logs.
- Windows ARM64 agent packages include an executable checksum and per-user Install/Update/Rollback/Uninstall helper. It verifies staged bytes/PE architecture, refuses changed or active installations, retains update backups, restores failed updates and preserves managed paths when uninstall is blocked. No elevation, service or driver changes. Verify the ZIP's release checksum before trusting the included executable checksum.
- The prior single setup flow remains: Windows selects your ARM64 ISO; Ubuntu Server selects an LTS release and downloads its signed/checksummed installer automatically. Missing QEMU/swtpm/7-Zip/GnuPG and Homebrew bootstrap are handled by setup. Complete local macOS prompts and guest installation/account steps yourself.

Validated:126 workspace tests passed/8 ignored, separately executed native X11 clipboard acceptance passed, 11 MCP tests passed, clippy/build/Mac ARM64 core check and Windows ARM64 cross-build passed. Actual desktop Send/Copy matched Unicode across two independent authenticated X11 displays using real native agents and a private stdio/socket proxy, without claiming a VM boot. Native Windows lifecycle CI passed with a real ARM64 MSVC artifact, including locked-manifest failure recovery and locked-executable uninstall preservation. [Evidence](https://github.com/puma2k/freelane/blob/main/docs/evidence/p2-lifecycle-clipboard.json).

Clipboard needs a graphical guest user session. Ubuntu Server without a desktop has no GUI clipboard; normal terminal copy/paste remains available. Windows/Mac native clipboard and normal-user guest startup acceptance still need verification. Mac HVF/Dock/physical-drive testing remains user-deferred. Continuous video, automatic clipboard sync, file transfer/document opening, accelerated3D/Metal and everyday Windows reliability are not accepted by this preview.

The Mac package is ad-hoc signed and not Apple-notarized. Read START-HERE.md, [clipboard instructions](https://github.com/puma2k/freelane/blob/main/docs/clipboard.md) and [agent lifecycle instructions](https://github.com/puma2k/freelane/blob/main/docs/agent-lifecycle.md). Rust dependency notices accompany Mac and Windows packages.
