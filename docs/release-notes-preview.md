FreeLane v0.1.0-preview.18 for Apple Silicon Macs (macOS14+).

Adds explicit file copies from Windows/Ubuntu guests back to the host through a separately selected guest outbox. Previous preview.17 features remain available; the full product roadmap remains in progress.

- Start the matching guest agent with `--export-root <existing-directory>` in the guest user session. In Display, enter the outbox filename, choose Receive file from guest, and select a host folder, including an external drive. CLI: `freelane file-receive vm.toml "Result.txt" /host/folder`.
- Inbox and outbox permissions are independent and disabled by default. Existing startup installation does not enable an outbox; stop that agent and explicitly run with the flag for the session. There is no automatic guest filesystem browsing or background file synchronization.
- Protocolv11 reads one regular file in bounded16KiB chunks, checks final source size/modification time, and compares SHA-256 before publishing on the host. Existing files are preserved; cancellation removes owned temporary output. No automatic retries, source deletion or opening of received files. The64GiB per-file transfer bound is not a virtual disk capacity limit.
- English/Vietnamese controls include filename, folder selection, progress and cancellation. The selected local host folder must be trusted against other processes replacing temporary entries. Do not edit source files during transfer; this is not an atomic source snapshot.

Validation:184 Rust checks passed/9ignored,14MCP checks, strict workspace/WindowsARM lint, WindowsARM64 build and Mac core cross-check. Native Linux agent/hostCLI transferred3MiB both directions with Unicode names, matching SHA-256, conflict preservation and empty-file acceptance. Actual EN/VI desktop controls also received verified files through an owned private Linux agent socket; the folder dialog was substituted with a fixed owned path. An8GiB sparse-source regression proves Begin returns before the host RPC deadline without hashing the entire file first.

Native Mac dialogs/filesystems, WindowsARM guest/channel, physical external drives, HVF/Dock/sleep/device acceptance and full Coherence video remain unverified. Minor: canceling through the shared RPC path can display an existing clipboard-specific message. Publisher signing/notarization, independent clones, live Windows sharing and advanced graphics remain open. Ad-hoc signed; VM prerequisites install through the existing setup flow.

Tiếng Việt: Thêm nhận file từ Windows/Ubuntu về máy chủ qua thư mục xuất riêng, có chọn thư mục nhận/ổ ngoài, tiến trình, hủy, xác minh SHA-256 và giữ nguyên file trùng tên. Cần agent mới chạy với `--export-root`; thư mục xuất mặc định tắt. Đây là sao chép hai chiều chủ động, chưa phải đồng bộ thư mục. Toàn bộ roadmap và kiểm thử Mac thực vẫn chưa hoàn tất.
